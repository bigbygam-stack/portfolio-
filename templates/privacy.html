PRIVACY POLICY

Last updated: October 30, 2026

This privacy notice for this personal portfolio website describes how and why I might collect, store, use, and/or process your information when you visit or interact with the platform, including when you fill out the contact log page form or communicate with integrated software features.

1. KEY POINTS SUMMARY

Do I collect sensitive information? No. This website does not process, request, or handle any sensitive personal identification attributes, healthcare records, or financial information.

Do I collect derivative data automatically? No. This platform runs clean architecture parameters hosted via server environments that do not employ automated logging, behavioral tracking scripts, or marketing cookie pixels.

Do I use third-party API services? Yes. This application connects to public programmatic modules (specifically weather infrastructure data networks) to render live operational elements on designated project dashboards.

2. INFORMATION I COLLECT

I collect personal information that you voluntarily choose to provide when filling out the communications layout fields on this website. The specific metrics are limited to:

  • Names: Provided voluntarily to identify the source of incoming correspondence.
  • Email Addresses: Provided voluntarily to enable direct response channels.
  • Message Contents: The text logs and open-ended text strings typed into the message box fields.

3. INTEGRATED ARTIFICIAL INTELLIGENCE CAPABILITIES

This website incorporates custom Artificial Intelligence features built upon the Anthropic platform execution architecture. These features function exclusively as a static AI search infrastructure tool.

The AI system operates strictly under the following parameters:

  • It processes conversational text prompts to query pre-fed professional resume skills, project listings, and historical documentation facts.
  • It is designed exclusively for user assistance and portfolio search layout navigation.
  • It does not track individual user identities, compile demographic analytics, generate profiling insights, or share context arrays with marketing platforms.

4. HOW I PROCESS YOUR INFORMATION

I process your contact information exclusively to manage and respond to incoming digital messages, ensure input security boundaries, and display conversational search arrays within the application's environment layout.

5. DATA RIGHTS AND TRANSFERS

Your data stays completely safe within my operational environment and is never sold or distributed. Because this project is hosted globally on Vercel infrastructure, information is processed via secure cloud parameters. In accordance with data guidelines, you preserve absolute authority to request the absolute removal of your message logs from the active database by submitting a deletion request.
